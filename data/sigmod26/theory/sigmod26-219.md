**Definition Table Overlap.** Let $T_1$ and $T_2$ be two tables of size $m_1 × n_1$ and $m_2 × n_2$, with cell values denoted by $c^ (1) $ and $c^ (2) $ respectively. Let $σ_1$ and $σ_2$ be row permutations for $T_1$ and $T_2$, and $ _1$ and $ _2$ be the corresponding column permutations. The overlap between $T_1$ and $T_2$ under the permutation tuple $ = (σ_1, _1, σ_2, _2)$ is the set of positions where the permuted cell values are equal. Formally, the permutation-dependent overlap is: \[ O_ = \ (i, j) c^ (1) _ σ_1(i),\, _1(j) = c^ (2) _ σ_2(i),\, _2(j) \ , \] where $1 ≤ i ≤ min(m_1, m_2)$ and $1 ≤ j ≤ min(n_1, n_2)$.

**Definition Common Subhypergraph.** Let $H_1 = (V_1, E_1)$ and $H_2 = (V_2, E_2)$ be two hypergraphs. A hypergraph $C = (V_C, E_C)$ is a common subhypergraph of $H_1$ and $H_2$ if there exist subsets $V_1' V_1$ and $V_2' V_2$ such that $C$ is isomorphic to both subhypergraphs $H_1[V_1'] = (V_1', E_1')$ and $H_2[V_2'] = (V_2', E_2')$. That is, there exist bijections $ _V : V_C V_i'$ and $ _E : E_C E_i'$ (for $i = 1,2$) such that for all $e E_C$ and $v V_C$, we have $v e$ if and only if $ _V(v) _E(e)$.

**Definition Maximum Clique Problem~\cite{karp2009reducibility.** Let $G = (V, E_G)$ be an undirected graph, where $V$ is a set of nodes and $E_G$ is a set of edges. A clique is a subset $K V$ such that every pair of distinct nodes in $K$ is connected by an edge, i.e., $\ u, v\ E_G$ for all $u, v K$ with $u ≠ v$. The goal is to find a clique $K V$ of maximum size, i.e., one that maximizes $|K|$ in $G$.

**Theorem Permutation Invariance.** Let $T$ be a table and $H(T)$ be its associated hypergraph. For any table $T'$ obtained by permuting the rows and/or columns of $T$, the hypergraphs $H(T)$ and $H(T')$ are isomorphic. Consequently, structural properties of the hypergraph representation are preserved under such permutations.

**Definition Hypergraph.** A hypergraph is defined as $H = (V, E)$, where $V = \ v_1, , v_ |V| \ $ is a finite set of nodes, and $E = \ e_1, , e_ |E| \ $ is a finite set of hyperedges, each of which is a non-empty subset of $V$. **Definition Row and Column Permutations.** Let $I = \ 1, , m\ $ denote the row indices of table $T$. A row permutation is a bijection $σ: I I$ that reorders the row indices by mapping each $i I$ to some position $σ(i) I$. Similarly, a column permutation is a bijection $ : J J$ for column indices $J = \ 1, , n\ $.

**Definition Maximum Common Subhypergraph.** Let $H_1$ and $H_2$ be two hypergraphs. A hypergraph $C^* = (V^*_C, E^*_C)$ is a maximum common subhypergraph of $H_1$ and $H_2$ if it is a common subhypergraph of both, and for any common subhypergraph $C = (V_C, E_C)$, it holds that $|V_C| ≤ |V^*_C|$.

**Definition Table.** A table $T$ is a two-dimensional structure with $m$ rows and $n$ columns, where each cell $c_ i,j $ denotes the value at the $i$-th row and the $j$-th column. Formally, $T = \ c_ i, j 1 ≤ i ≤ m,\ 1 ≤ j ≤ n\ $.

**Proof.** Proof by construction. Let $T$ be a table with rows indexed by $I$ and columns by $J$. Let $T'$ be the table obtained from $T$ by applying a row permutation $σ$ to the rows and a column permutation $ $ to the columns, that is, $T'(σ(i), (j)) = T(i,j)$ for all $(i,j) I× J$. Node Set. We construct the hypergraph $H(T)$ by creating one node $v_ i,j $ for each cell $(i,j)$ of $T$. Since row and column permutations do not change the multiset of cell values, the node sets of $H(T)$ and $H(T')$ coincide, that is, $V = V' = \ v_ i,j (i,j) I × J\ $. Hyperedge Set. In $H(T)$, we define $i$-th row-hyperedge $e_i = \ v_ i,j j J\ for each i I$, and $j$-th column-hyperedge $f_j = \ v_ i,j i I\ for each j J$. Similarly in $H(T')$, we define $e'_ σ(i) = \ v_ σ(i), (j) j J\ $ and $f'_ (j) = \ v_ σ(i), (j) i I\ $. Isomorphism. Let $ _V:V V'$ be the identity map on the node set, since $ _V(v) = v$. We define the hyperedge bijection $ _E$ by $ _E(e_i) = e'_ σ(i) $ and $ _E(f_j) = f'_ (j) $. For every node $v$ and hyperedge $e \ e_i,f_j\ $, we have $v e _V(v) _E(e)$, hence $( _V, _E)$ is an incidence-preserving pair of bijections, i.e., an isomorphism. Therefore, $H(T)$ and $H(T')$ are isomorphic hypergraphs. Since hypergraph isomorphism preserves all structural properties including node-hyperedge incidence and hyperedge sizes, the proof is complete.

**Proof.** Proof by construction . Direction 1: From Table Overlap to Common Subhypergraph. Recall from Definition~ [ref] that $O_ ^* $ is the between $T_1$ and $T_2$ achieved under optimal row and column permutations. Each cell $c$ in a table corresponds to a node $v$ in the associated hypergraph. Therefore, the set of overlapping cells defines a set of nodes $V_C V_1 V_2$, where each node $v V_C$ corresponds to a matching cell in the overlap. The hypergraph construction includes one hyperedge per row and column, connecting all cells in the respective row or column. Hence, the rows and columns in the overlapping cells induce structurally identical row- and column-hyperedges in both $H(T'_1)$ and $H(T'_2)$. Let $C$ be the subhypergraph induced by the nodes in $V_C$, along with their corresponding row- and column-hyperedges. Since the overlap $O_ ^* $ is maximal by construction, $C$ is the maximum common subhypergraph of $H(T'_1)$ and $H(T'_2)$. Direction 2: From Common Subhypergraph to Table Overlap. Conversely, let $C^*$ be the maximum common subhypergraph of $H(T_1)$ and $H(T_2)$ with node set $V_C$. By the construction of the hypergraphs, each node $v V_C$ corresponds to matching cells in $T_1$ and $T_2$. The hyperedges of $C^*$ correspond to the rows and columns containing these overlapping cells. By Theorem~ [ref] , the hypergraph structure is invariant under row and column permutations. Therefore, we can permute the rows and columns of $T_1$ and $T_2$ such that the corresponding cells associated with $V_C$ are aligned in the same positions in both tables. This alignment yields a table overlap of size $|V_C|$. Suppose, for contradiction, that there exists an overlap larger than $|V_C|$. Then, by the construction in Direction 1, this larger overlap would induce a common subhypergraph with more nodes than $C^*$, contradicting its maximality. Hence, the overlap induced by $C^*$ is the largest possible.

**Proof.** We prove the theorem via a reduction from the maximum clique problem, which is NP‐hard~ [cite] . [Maximum Clique Problem~ [cite] ] Let $G = (V, E_G)$ be an undirected graph, where $V$ is a set of nodes and $E_G$ is a set of edges. A clique is a subset $K V$ such that every pair of distinct nodes in $K$ is connected by an edge, i.e., $\ u, v\ E_G$ for all $u, v K$ with $u ≠ v$. The goal is to find a clique $K V$ of maximum size, i.e., one that maximizes $|K|$ in $G$. Let $G = (V, E_G)$ be an instance of the maximum clique problem. We construct two hypergraphs $H_1$ and $H_2$ as follows: [leftmargin=*] ; $H_1 = (V, E_1)$, where $E_1 = \ \ u, v\ (u, v) E_G\ $. In this case, $H_1$ is simply the original graph $G$ viewed as a hypergraph, where each hyperedge consists of exactly two nodes, corresponding to the edges of the original graph. ; $H_2 = (V, E_2)$, where $E_2 = \ \ u, v\ u, v V, u ≠ v\ $. Here, $H_2$ represents the complete graph on the node set $V$, which is also viewed as a hypergraph with every pair of distinct nodes forming a hyperedge. Consider any subset $V_C V$. By Definition~ [ref] , a common subhypergraph $C = (V_C, E_C)$ of $H_1$ and $H_2$ is an induced subhypergraph on $V_C$, where $E_C$ contains all hyperedges in both $H_1$ and $H_2$ when restricted to $V_C$. Since $H_2$ is the complete graph, any pair of distinct nodes in $V_C$ is present in $E_2$. Thus, $E_C$ consists of those hyperedges in $E_1$ that are induced by $V_C$. For $E_C$ to contain all possible pairs in $V_C$, every such pair must also exist in $E_1$, i.e., $V_C$ must form a clique in $G$. Thus, finding a maximum common subhypergraph of $H_1$ and $H_2$ is equivalent to finding a maximum clique in $G$. Since the construction of $H_1$ and $H_2$ from $G$ is achievable in polynomial time, if there is a polynomial-time algorithm that finds the optimal solution $C^*$ to our problem, then we can solve the maximum clique problem optimally. This is not possible unless $ P = NP $. Therefore, the maximum common subhypergraph problem is NP‐hard.

**Proof.** The reduction in the proof for Theorem~ [ref] is approximation-preserving. Specifically, any common subhypergraph $C$ of size $|K|$ corresponds directly to a clique of size $|K|$ in $G$. Therefore, an algorithm that approximates the maximum common subhypergraph problem within a factor better than $|V|^ 1 - $ would yield an approximation algorithm for the maximum clique problem with the same guarantee. However, it is known that the maximum clique problem cannot be approximated within a factor of $|V|^ 1 - $ for any $ > 0$ unless $ P = NP $~ [cite] . This contradiction implies that no such approximation algorithm exists for the maximum common subhypergraph problem.
