**Lemma .** The outer loop converges to a local minimum of $L( Q ,O)$ in a finite number of iterations. We note that the status of orders $O$ is in a discrete space and thus the number of possible orders is finite. The number of possible partitions $ Q $ is also finite. Therefore, the number of possible combinations of $ Q $ and $O$ is finite. We then prove that each possible combination of $ Q $ and $O$ appears at most once by OCL. We note that given $ Q ^ \ E_1\ = Q ^ \ E_2\ $, where $E_1≠ E_2$, the corresponding $O^ \ E_1+1\ $ and $O^ \ E_2+1\ $ can be computed accordingly, satisfying $O^ \ E_1+1\ =O^ \ E_2+1\ $. Then we can obtain their corresponding partitions $ Q ^ \ E_1+1\ $ and $ Q ^ \ E_2+1\ $ at the convergence of the next inner loop, satisfying $ Q ^ \ E_1+1\ = Q ^ \ E_2+1\ $. It is clear that $L( Q ^ \ E_1+1\ , O^ \ E_1+1\ )=L( Q ^ \ E_2+1\ , O^ \ E_2+1\ )$. However, the sequence $\ L( Q ^ \ 1\ , O^ \ 1\ ), L( Q ^ \ 2\ , O^ \ 2\ ), ..., L( Q ^ \ E\ , O^ \ E\ )\ $ is monotonically decreasing. Hence, the result follows.

**Lemma .** The inner loop converges to a local minimum of $L( Q , O )$ in a finite number of iterations with fixed $ O $. Note that the number of possible partitions $ Q $ is finite for a dataset with a finite number of objects $n$. We then illustrate that each possible partition $ Q $ occurs at most once by OCL. Assume that two optimizers satisfy $ Q ^ \ I_1\ = Q ^ \ I_2\ $, where $I_1≠ I_2$. Then it is clear that $L( Q ^ \ I_1\ ,O^ \ E\ )=L( Q ^ \ I_2\ ,O^ \ E\ )$. However, the value sequence of the objective function $\ L( Q ^ \ 1\ ,O^ \ E\ ), L( Q ^ \ 2\ ,O^ \ E\ ), ..., L( Q ^ \ I\ ,O^ \ E\ )\ $ generated by OCL is strictly decreasing. Hence, the result follows.

**Theorem .** OCL algorithm converges to a local minimum in a finite number of iterations.
