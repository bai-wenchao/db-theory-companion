Therefore, threads will not compete to write data, preventing starvation. Instead, writers exhibit data dependencies. In a tree updated by path copying, a parent node is always created in a version that is no earlier than its child nodes. Specifically, the child node on the search path shares the same version as it parent node, while the versions of other child nodes are earlier than that of the parent node.
