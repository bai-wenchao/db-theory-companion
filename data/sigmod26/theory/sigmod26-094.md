Theorem 2 does not follow from the NP-hardness of SubIso. Rather, it targets EnumP, the class of enumeration problems with PTIME verification, not decision problems in NP. It shows that for EnumP-complete problems such as SubIso, no algorithm can be both output-polynomial and 𝛽-robust for any constant 𝛽, thereby ruling out attempts to achieve both properties simultaneously. The result does not extend to all NP-complete problems. For example, the edge dominating set problem is NP-complete [45], yet its enumeration is output-polynomial, i.e., all minimal edge dominating sets can be listed in polynomial time in the sizes of both input and output [47, 92]. Moreover, its enumeration is also 1-robust (i.e., 𝛽 = 1), since it is an exact algorithm and returns all minimal edge dominating sets [47]. Thus, for such problems, both properties are simultaneously attainable, as opposed to SubIso.
